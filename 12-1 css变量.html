1. 基本用法

在 :root 中定义变量，用 var(--变量名) 引用。本页的背景色、文字色、圆角、阴影等都来自 CSS 变量。

5. 代码示例

:root {
  --primary-color: #4a90e2;
  --spacing: 16px;
}

.card {
  background: var(--card-bg);
  padding: var(--spacing);
  color: var(--undefined-color, #e74c3c); /* 带回退值 */
}
