6. 与 Font Awesome 的核心区别

  • 渲染方式：Lucide 用内联 SVG；FA 字体图标用 webfont + CSS pseudo（:before）
  • 颜色控制：Lucide 通过 color → stroke；FA 直接 color 改变字体颜色
  • 粗细可调：Lucide 原生支持 stroke-width；FA 字体图标粗细固定（需换 style）
  • 体积：SVG 可 tree-shake；字体图标必须加载完整字体文件
  • 可访问性：内联 SVG 更易被屏幕阅读器识别

CDN 信息

Lucide（SVG 图标模式）
CDN: https://unpkg.com/lucide@latest
使用:
  HTML:  <i data-lucide="icon-name"></i>
  JS:    lucide.createIcons();
可选属性: data-lucide-size / data-lucide-stroke-width / data-lucide-color
