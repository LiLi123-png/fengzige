JavaScript 六种基础数据类型演示

六种基础数据类型（原始类型 / Primitive Types）

string字符串"你好"
number数字42 / 3.14 / Infinity / NaN
boolean布尔true / false
undefined未定义未赋值的变量
null空值主动赋值的空引用
symbol唯一标识Symbol("key")

另外还有 bigint（大整数，ES2020）和 object（引用类型），不在"六种"范围内。

代码示例

// 1. string  —— 字符串
var fzg_name = "冯子格";
var fzg_greet = 'Hello' + " World";

// 2. number  —— 数字（整数、小数、特殊值）
var fzg_age = 25;
var fzg_pi = 3.14159;
var fzg_inf = Infinity;
var fzg_nan = NaN;

// 3. boolean —— 布尔（只有 true / false）
var fzg_isOk = true;
var fzg_notOk = false;

// 4. undefined —— 未定义（变量声明但未赋值）
var fzg_undefinedVal;

// 5. null —— 空值（主动赋值为 null）
var fzg_nullVal = null;

// 6. symbol —— 唯一标识符（ES6 新增）
var fzg_sym = Symbol("fzg_key");
