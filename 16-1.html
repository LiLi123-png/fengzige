二、map / filter / reduce —— 数据加工流水线（不改变原数组）

      
红色圆片是满足 filter 条件（偶数）的元素。

      
var fzg_nums = [1, 2, 3, 4, 5, 6, 7, 8];
fzg_nums.map(fzg_x => fzg_x * 2)                  // 每个元素 ×2
fzg_nums.filter(fzg_x => fzg_x % 2 === 0)         // 筛出偶数
fzg_nums.reduce((fzg_a, fzg_b) => fzg_a + fzg_b)  // 累加成 1 个值

四、查找、拼接与遍历

      
var fzg_fruits = ["苹果", "香蕉", "橘子", "香蕉"];
fzg_fruits.indexOf("香蕉")        // 查下标，1
fzg_fruits.includes("橘子")       // 是否存在，true
fzg_fruits.concat(["葡萄"])       // 拼接新数组
fzg_fruits.join("、")             // 拼成字符串
fzg_fruits.forEach(...)           // 逐个遍历

      

    


    
    

      
五、主要数组方法速查表

      

        
方法作用改变原数组返回值

        
push / pop尾部添加 / 删除是新长度 / 被删元素

        
unshift / shift头部添加 / 删除是新长度 / 被删元素

        
splice任意位置增删替换是被删元素数组

        
sort / reverse排序 / 翻转是原数组（已变）

        
map逐个变换，生成新数组否新数组

        
filter按条件筛选否新数组

        
reduce累计归约为一个值否累计结果

        
slice截取一段否新数组

        
concat / join拼接数组 / 转字符串否新数组 / 字符串

        
indexOf / includes查找下标 / 是否存在否数字 / 布尔值

        
find / findIndex按条件找元素 / 下标否元素或 undefined / 数字

        
forEach纯遍历，无返回看回调undefined
