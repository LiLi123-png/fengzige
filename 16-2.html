制作：冯子格

一、对象 —— 一张会变的属性卡片

对象由"键: 值"组成。蓝色是键（属性名），白色是值。点按钮实时增删属性。


      

      
      
      
      
      

    


    
    

      
二、对象遍历 —— for...in 与 Object.keys / values / entries

      
for (var fzg_key in fzg_student) { /* 遍历属性名 */ }
Object.keys(fzg_student)      // 所有键
Object.values(fzg_student)    // 所有值
Object.entries(fzg_student)   // [键, 值] 数组

      

    


    
    

      
三、字符串 —— 也可以看成"字符数组"

      
紫块=汉字，橙块=数字，灰块=空格。灰色小字是下标，字符串也有 length 和下标访问。

      
var fzg_str = "Hi 冯子格 228";
fzg_str.length            // 长度（空格也算 1 个）
fzg_str[0] / fzg_str.at(-1)   // 按下标取字符，at(-1) 取最后一个

      

      

    


    
    

      
四、字符串常用方法 —— 点按钮看结果（原字符串不变）

      
fzg_str.slice(0, 2)            // 截取 "Hi"
fzg_str.indexOf("冯")          // 查位置
fzg_str.includes("228")        // 是否包含
fzg_str.replace("228", "666")  // 替换
fzg_str.split(" ")             // 按空格拆成数组
fzg_str.trim() / toUpperCase() / repeat(2)

      

      

        
        
        
        
        
        
        
        
        
      

      

    


    
    

      
五、对象与字符串速查表

      

        
操作写法说明

        
对象 访问属性fzg_obj.fzg_key 或 fzg_obj["fzg_key"]点语法简洁，方括号可用变量

        
对象 新增/修改fzg_obj.fzg_key = 值键存在即修改，不存在即新增

        
对象 删除属性delete fzg_obj.fzg_key属性彻底移除

        
对象 遍历for...in / Object.keys / values / entriesin 遍历键，entries 键值成对

        
对象 方法与 thisfzg_sayHi: function() { return this.fzg_name; }this 指向调用时的对象

        
字符串 取字符fzg_str[i] / fzg_str.at(-1) / charAt(i)at 支持负下标

        
字符串 截取slice(起, 止) / substring(起, 止)含头不含尾，不改原字符串

        
字符串 查找indexOf / includes / startsWith返回位置或布尔值

        
字符串 变换replace / toUpperCase / trim / concat字符串不可变，均返回新串

        
字符串 拆分拼接split(" ") 拆成数组，join(" ") 数组转字符串与数组方法互相配合

        
字符串 模板字符串`姓名：${fzg_name}`反引号 + ${} 直接嵌变量
